Audit fixes applied to the existing CRM

This implementation retains the existing CRM, customer ledger, order ledger and technology stack. The earlier workflow audit is a point-in-time assessment; its full module roadmap extends beyond the defects fixed in this release.

Audit findingImplemented behaviour
Delivery stock isolationDelivery completion consumes only its fulfilment group's active reservations. Repeated product lines require their combined quantity. Booking collisions are rejected and rescheduling updates the working delivery date.
Purchase totalsOnly active purchase item revisions contribute to totals. Previous item versions remain in history.

Reports label unreviewed variable costs as provisional. Supplier sales attribution uses supplier lines on mixed orders.

Shopify connection

Store: ah-interior-nelson-ltd.myshopify.com. Open Shopify in the CRM and select Connect store to enter its Admin API access token. The token is encrypted on the server and excluded from settings responses and audit payloads.

  • Manual sync reads accessible orders from the last 59 days, ten orders per page, with an explicit continuation button.
  • Variant ID or unique SKU suggests an existing CRM product. A manager reviews product mappings and fulfilment routes.
  • Import creates one canonical CRM order and draft invoice, reuses an unambiguous customer email match, preserves the shipping address, snapshots product costs and maintains exact pennies.
  • Duplicate imports return the existing order. Later Shopify changes flag the linked order for review instead of overwriting staff work.
  • Cancelled, refunded, fulfilled, international, tax-exclusive, incomplete and unreconciled-total orders remain in review. The current connector does not push inventory, fulfilments, payments or refunds to Shopify.

API reference: Shopify Order and LineItem. The GraphQL query passed Shopify's schema validator for 2026-07.
